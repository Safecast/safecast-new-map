##  Upload to Codeberg

### Option 1: Git Push (Recommended)

```bash
# Clone the wiki repository
git clone https://codeberg.org/Safecast/safecast-new-map.wiki.git

# Copy wiki files
cp wiki/*.md safecast-new-map.wiki/

# Commit and push
cd safecast-new-map.wiki
git add *.md
git commit -m "Add comprehensive wiki documentation (15 pages)

Co-authored-by: Qwen-Coder <qwen-coder@alibabacloud.com>"
git push
```

### Option 2: Manual Upload via Web Interface

1. Go to: https://codeberg.org/Safecast/safecast-new-map/wiki
2. Click "New page" for each markdown file
3. Copy content from each `.md` file
4. Use the filename (without `.md`) as the page title
5. Save each page

### Option 3: Using SSH

```bash
# Clone with SSH
git clone git@codeberg.org:Safecast/safecast-new-map.wiki.git

# Copy and push
cp wiki/*.md safecast-new-map.wiki/
cd safecast-new-map.wiki
git add *.md
git commit -m "Add comprehensive wiki documentation"
git push
```
